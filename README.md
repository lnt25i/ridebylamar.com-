# RIDE public website

Premium marketing site for [ridebylamar.com](https://ridebylamar.com). Deploy from this folder on Vercel — see `DEPLOYMENT.md`.

## Content files (edit these)

| File | Purpose |
|------|---------|
| `content/site.ts` | Brand, email, domain, nav, homepage, about, footer |
| `content/app-links.ts` | App Store & Google Play URLs |
| `content/social-links.ts` | X, Instagram, Facebook, YouTube, TikTok, LinkedIn |
| `content/shop.ts` | Amazon storefront & product categories |
| `content/legal.ts` | Legal policy text |
| `content/faqs.ts` | Support FAQ |
| `content/careers.ts` | Driver careers copy & requirements |
| `content/contact.ts` | Contact form labels & topics |

## Assets

- `public/ride-logo.png` — official wordmark  
- `public/app-icon.png` — home-screen app icon  

## Commands

```bash
npm run dev
npm run build
npm run lint
```
